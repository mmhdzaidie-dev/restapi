ZEIA REST API

Vercel-ready API documentation · JSON endpoints · no player UI

Base URL: https://YOUR-DOMAIN.vercel.app OpenAPI JSON /docs
Deployment: push this repository to GitHub and import it into Vercel. No build command is required; Vercel detects the root api/ directory as serverless functions.

Endpoints

GET /api/search

Search

Search songs, albums, playlists and artists via YouTube Music.

?query=shape%20of%20you&type=all
GET /api/suggest

Suggestions

Search suggestions.

?q=adele
GET /api/artist

Artist

Artist metadata, songs, albums, videos, playlists and related artists.

?id=UC...
GET /api/album

Album

Album or playlist metadata and track list.

?id=MPREb_...
GET /api/lyrics

Lyrics

Primary lyrics pipeline with optional title and artist hints.

?id=VIDEO_ID&title=...&artist=...
GET /api/lyrics1

Lyrics 1

LRCLIB-based lyrics pipeline.

?id=VIDEO_ID
GET /api/lyrics2

Lyrics 2

Transcription-based lyrics fallback pipeline.

?id=VIDEO_ID
POST /api/ytplay

Audio extraction

Returns an extracted audio URL from the configured providers.

{"query":"https://youtu.be/VIDEO_ID"}
POST /api/transcribe

Transcribe

Creates transcription data with synced word/line timing.

{"url":"https://youtu.be/VIDEO_ID"}
POST /api/translate

Translate

Translate text or arrays of lyric lines.

{"text":"hello","targetLang":"id"}
GET /api/proxy-audio

Audio proxy

Streams upstream audio and forwards Range headers for seeking.

?url=https%3A%2F%2F...
GET /api/proxy-image

Image proxy

Streams an upstream image through the API.

?url=https%3A%2F%2F...

Quick examples

curl "https://YOUR-DOMAIN.vercel.app/api/search?query=adele&type=songs"

curl "https://YOUR-DOMAIN.vercel.app/api/lyrics?id=VIDEO_ID"

curl -X POST "https://YOUR-DOMAIN.vercel.app/api/ytplay" \
  -H "content-type: application/json" \
  -d '{"query":"https://www.youtube.com/watch?v=VIDEO_ID"}'

curl "https://YOUR-DOMAIN.vercel.app/api/proxy-audio?url=https%3A%2F%2Fexample.com%2Faudio.mp3"
